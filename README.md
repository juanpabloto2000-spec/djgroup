# JD GROUP AXM — PLATAFORMA DIGITAL & FRONTEND INTERACTIVO
## Sensory Luxury & Digital Intimacy · Armenia, Quindío

Este repositorio contiene la implementación modular y desacoplada del frontend interactivo y plataforma digital para **JD Group AXM** en Armenia, Quindío. Diseñado y construido bajo el estándar **AI Project OS Core v1.0** y el paradigma agéntico en **Google Antigravity**.

---

## 🏗️ Arquitectura Modular (LEGO Design)

El proyecto está organizado en módulos desacoplados con contratos de interfaz claros:

* **`src/theme.py` (M00):** Core Design System, tokens cromáticos (*Super Dark Mode*) y estilos CSS atómicos.
* **`src/components/age_gate.py` (M01):** Control perimetral de mayoría de edad (+18 Gate) y cumplimiento normativo.
* **`src/components/header.py` (M01/M02):** Header de marca con monograma VIP y *Dual-Funnel Switcher* (Ruta Talento vs. Ruta VIP).
* **`src/components/calculator.py` (M02):** Motor interactivo de proyecciones financieras en USD y COP (Sede 50-60% vs Satélite 80-95%).
* **`src/components/sets_tour.py` (M02):** Recorrido interactivo por los sets temáticos de Armenia (*Velvet Luxury*, *Neón Cyberpunk*, *Nórdico Minimalista*).
* **`src/components/corporate_panel.py` (M02):** Portal institucional con especificaciones técnicas 4K y respaldo legal.
* **`src/components/lead_form.py` (M03):** Formulario confidencial de postulación con cifrado simulado y aceptación estricta de Habeas Data.
* **`src/services/data_service.py` (M04):** Servicio dinámico de tasa de cambio (TRM USD/COP) y utilidades financieras.
* **`app.py`:** Orquestador principal que ensambla todos los módulos.

## 🚀 Instrucciones de Ejecución

### Requisitos Previos
* Python 3.10+ (Recomendado 3.12)
* Dependencias listadas en `requirements.txt`

### Instalación y Despliegue Local

1. Instalar dependencias:
```bash
pip install -r requirements.txt
```

2. Ejecutar la aplicación en Streamlit:
```bash
streamlit run app.py
```
